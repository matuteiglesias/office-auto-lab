# Job Search vertical dogfood — 2026-10-07

## Result

The live shelf proved the vertical can separate application preparation, process follow-up, waiting, closure, contact resolution, and material readiness without creating a second ATS.

## Findings

- ATS `Current` already owned the operational action layer, including exact action/follow-up dates and process contact routes. The Office packet now composes those fields instead of reconstructing timing from prose when structured values exist.
- Same-name entries in Google Contacts are not enough to verify a recruiter. Process Gmail evidence is accepted; CRM/PERSONAS remains separate relationship truth.
- Direct applications do not become blocked merely because no warm contact exists.
- Drive search was not a trustworthy authority for which CV or template is current. A native human-owned `Assets` table was added inside ATS instead of creating another tracker.
- Application-prep truth now distinguishes approved current assets from review-required candidates, historical references, known missing assets, and unregistered gaps.
- The quiet watch suppresses unchanged repeated states by deterministic fingerprint.

## Initial attention behavior

The first dogfood state intentionally surfaced one due scheduling follow-up and one immediate deadline/material blocker, while suppressing a closed process that had already received a feedback reply and avoiding daily nagging for normal-priority CV preparation.

## Stop boundaries

The vertical does not autonomously submit applications, send recruiter messages, mutate ATS, accept/create Calendar commitments, add every recruiter to CRM, or promote generated/historical application material to `approved_current`.

## Next promotion triggers

1. Explicitly review and approve at least one role-family CV base before automating role-specific derivation.
2. Add a post-submission follow-up rule only after repeated real cases justify it.
3. Build a separate interview-preparation packet only after a live scheduled interview demonstrates the need.
4. Enable one daily condition watch only when a ChatGPT task slot is intentionally available.
